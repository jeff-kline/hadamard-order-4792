# Corrections and versions

Version 0.1.0 is the first edition of this paper.

Please report corrections through the repository issue tracker with the affected version, statement or input, and a reproducible calculation or source. A verified earlier construction of order 4792 warrants a dated attribution update. A mathematical error warrants a correction or withdrawal identifying the affected claims. A replacement release will identify the version it supersedes. Archived versions retain their original contents.
